# 📚 Digital Library (My Learning Project)

Hello! 👋 This is a simple web application I built to practice my front-end development skills. It's a Digital Library platform that lets you search for books using the free [OpenLibrary API](https://openlibrary.org/developers/api). 

You can look up books by their title, author, or genre, and see what the OpenLibrary database has to offer!

## ✨ What it does

*   **Search for Books:** Type in an author or book name to see a list of results.
*   **Browse by Genre:** Find books based on specific categories or subjects.
*   **View Details:** See info about the books, like the title, author, and sometimes the cover image.
*   **Simple & Clean:** A straightforward interface that is easy to use.

## 🛠️ Built With (Tech Stack)

I kept things simple and built this without any heavy frameworks. 

*   **HTML5** - For the structure of the pages.
*   **CSS3** - For styling and making it look nice.
*   **Vanilla JavaScript** - For fetching data from the API and updating the webpage dynamically.
