# Simon Says Game 🎮

A memory game built using HTML, CSS, and JavaScript. Click the buttons in the correct order to repeat the pattern.

## How it works
- The game shows a random sequence of colors.
- You must click the same colors in the same order.
- The sequence gets longer every round.

## Features

- Mobile Friendly
- Uses Local Storage to save your high score
- Sound effects for immersive game experience
- Volume control and user guide for beginners
