# Random Cat Fact Generator

A modern and responsive **Random Cat Fact Generator** built using **HTML, CSS, and JavaScript and API**. The application fetches random cat facts from a public REST API and displays them in a clean, minimal, and user-friendly interface.

---

## About the Project

Random Cat Fact Generator is a frontend web application that demonstrates how to consume a public REST API using the **Fetch API** and **Async/Await** in JavaScript.

With a single click, users can generate interesting and educational facts about cats. The project focuses on clean UI design, responsive layout, and modern frontend development practices.

---

## Features

- Generate random cat facts instantly
- Live API integration
- Fast and responsive interface
- Clean and modern UI
- Responsive design
- Interactive button hover effects
- Scrollable fact area for long facts
- Built using semantic HTML and modern CSS
