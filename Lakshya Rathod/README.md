# 🎓 University Finder

A simple web application to search universities by country using the Hipolabs Universities API.

## Features
- Search universities by country
- Fast API integration with Axios
- Responsive user interface
- Modern CSS styling
- Smooth animations
- Beginner-friendly project

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Axios
- Universities API

## Project Structure
```
University-Finder/
│── index.html
│── style.css
│── app.js
│── README.md
```

## API
https://universities.hipolabs.com/search?country=India

## How to Use
1. Open the project.
2. Enter a country name.
3. Click **Search**.
4. View the list of universities.
