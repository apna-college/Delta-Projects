# 🎮 Hangman Game  

A simple, interactive Hangman word-guessing game built with **HTML, CSS, and JavaScript**. The player tries to guess the hidden word one letter at a time before running out of attempts.  

---

## ✨ Features  
- 🔠 Random word selection each round  
- 🎨 Responsive UI with clean design  
- 🖼️ Win/Loss modals with images (`victory.gif` / `lost.gif`)  
- 🔄 Play Again button to restart without refreshing  
- 📖 Words revealed at the end of the game  
- 🎯 Tracks correct guesses and shows progress in real-time  

---

## 🛠️ Technologies Used  
- **HTML5** – Game structure  
- **CSS3** – Styling & layout  
- **JavaScript (ES6)** – Game logic and interactivity  

---

## 🚀 Getting Started  

### Clone the repository:
```bash

```

Open in browser:
Just open index.html in your browser.
